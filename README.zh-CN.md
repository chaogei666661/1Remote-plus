# 1Remote Plus

[![version](https://img.shields.io/github/v/release/chaogei666661/1Remote-plus?color=Green&include_prereleases&sort=semver)](https://github.com/chaogei666661/1Remote-plus/releases)
[![issues](https://img.shields.io/github/issues/chaogei666661/1Remote-plus)](https://github.com/chaogei666661/1Remote-plus/issues)
[![license](https://img.shields.io/github/license/chaogei666661/1Remote-plus?color=blue)](https://github.com/chaogei666661/1Remote-plus/blob/main/LICENSE)
![build](https://github.com/chaogei666661/1Remote-plus/actions/workflows/build-on-dev-push.yml/badge.svg)

1Remote Plus 是一款 Windows 上的个人远程会话管理器与启动器。它把你要连的所有机器——RDP、SSH、VNC、Telnet、
SFTP、FTP、串口、RemoteApp——收进一份可搜索的列表，并以标签页的形式集中打开，也可以让每个会话独占一个窗口。

> **这是一个修改版。**
> 本仓库 [`chaogei666661/1Remote-plus`](https://github.com/chaogei666661/1Remote-plus) 是
> [`chaogei/1Remote-Plus`](https://github.com/chaogei/1Remote-Plus) 的分支，而后者又源自原作者 Shawn Veck 的
> [1Remote/1Remote](https://github.com/1Remote/1Remote)。与上述两个项目均无隶属关系，也未获得其背书。
> **本版本**的问题请提交到 [chaogei666661/1Remote-plus/issues](https://github.com/chaogei666661/1Remote-plus/issues)；
> 如果 `chaogei/1Remote-Plus` 里也存在同样的问题，提到那边更合适。
>
> 本分支自行构建并发布 Release，应用内的更新检查读取的是本仓库的 releases 页面，而不是任何一个上游。

磁盘上的名字维持原样：可执行文件仍叫 `1Remote.exe`，配置和数据库仍叫 `1Remote.json`、`1Remote.db`，
`AppData` 目录仍叫 `1Remote`。这是刻意为之，这样已经在用的安装升级后不会丢数据、丢开机自启，也不会丢已保存的
凭据。

## 本分支改了什么

本分支于 2026 年 8 月从上游分出。下面这些都是本分支新增的，上游没有。

**修复**

- **代理终于能用了。** 在分出来的那个版本里，配置了代理其实根本没有建立任何隧道。本分支围绕本地中转重写了
  代理逻辑，并且会话会保留真实的目标地址，不再被改写成本地隧道的端点。
- **一批 checked 运算溢出**，它们会让图标加载、文件传输、凭据弹窗和创建桌面快捷方式直接崩溃。
- **界面卡死。** 凭据读写、SSH 端口转发的建立、SFTP 传输、数据源定时重载、服务器列表重建都被挪出了 UI 线程，
  网络一慢不会再把整个窗口连同其中承载的所有会话一起冻住。
- **文件传输不再丢文件，扫描也不再卡住。** 传输开始前会逐个检查文件是否与已排队的文件重复，用的是**语言学**
  比较——它按「人读起来是不是同一个词」来判断，于是 `file.txt` 和 `ﬁle.txt`（fi 连字）被当成同一个文件，
  只差一个零宽空格、一个软连字符，或者重音符号用预组合还是组合字符书写的名字也一样。最后这种一点都不罕见：
  macOS 写出来的文件名就是分解形式。多出来的那个文件会被直接从传输里丢掉，任何地方都不会出现。这个检查还是
  平方复杂度：两万个文件的目录大约要花 10 秒、五万个大约一分钟卡在「扫描中」，一个字节都还没传。现在两者都
  只需毫秒级，而仅大小写不同的路径仍然视为同一个文件——但传输面板会把这些条目点名列出，因为区分大小写的服务器
  可以同时存放 `Makefile` 和 `makefile`，Windows 不行，其中一个就是没有传到的文件。

**新功能**

- **所有协议都能走代理**——SOCKS4、SOCKS4a、SOCKS5、HTTP CONNECT，外加 **SSH 跳板机**（相当于 OpenSSH 的
  `ProxyJump`）。由于走的是本地中转，RDP 和 VNC 同样覆盖，不只是终端类协议。
- **常驻端口转发**——本地、远程、动态（SOCKS）三种 SSH 隧道，独立于会话运行，可随程序自动启动。
- **备份与还原**，并可把同一个备份包上传到 **WebDAV** 目录。
- **主机身份校验**，默认开启：RDP 证书、SFTP 与跳板机的 SSH 主机密钥、FTPS 证书都会与记住的指纹比对，也可以
  按服务器显式关闭。
- **连接时从密码管理器现取密码**，用 `cmd://` 引用任意命令行工具。
- **连接质量指示**——可选的定时探测，按往返时延、抖动和无响应比例给每台可见服务器分级，而不只是通/断。
- **网络唤醒（WoL）**，在服务器的操作菜单里。
- **从 `~/.ssh/config` 导入**，其中的 `ProxyJump` 会一并处理。
- **发送命令**——把同一条命令一次输入到多个已打开的终端会话，并可保存常用命令。
- **终端会话录制**到文件。
- 搜索范围更广，并支持按最近连接时间排序。

**外观**

- 全局改用半透明的 **亚克力 / 毛玻璃** 视觉语言，并提供面板不透明度滑块。
- 字体图标全部换成矢量路径，任何 DPI 下都不发虚。
- 新增 8 套为毛玻璃调校的配色：Mica Slate、Nord Frost、Tokyo Night、Catppuccin Mocha、Emerald Glass、
  Cyber Neon、Rose Pine、macOS Light Glass，经典配色仍然保留。

**发布**

- 发布包由本仓库自己构建和发布，程序内的更新检查读取的也是本分支的 releases，而不是上游的。

**`chaogei666661/1Remote-plus` 追加的加固**

- 使用**占位加密盐**构建出来的程序，会在启动时和「关于」页面里明确提示，而不是默默用一把公开的钥匙去加密真实密码。
- **`cmd://` 外部密码必须先在本机获得一次批准**才会执行，被篡改的数据库或导入的配置无法把密码字段变成代码执行入口。
- **WebDAV 备份拒绝明文 HTTP**，除非显式开启，开关旁边有明确警告。
- 生成的 **`.rdp` 文件和私钥副本按会话隔离存放**，会话结束即清理。
- 凭据令牌**先落盘再返回**，且写入不再阻塞 UI 线程。
- **克隆服务器不会再与原条目共享备用凭据和启动参数**。
- 新增**关闭看门狗**，在失效保护强杀进程之前先说明还有什么在运行。
- **测试工程纳入 CI 构建并运行**，Pull Request 与推送都会跑，同时用 Dependabot 跟踪 Actions 和 NuGet 依赖。备份
  还原（含 Zip-Slip 尝试）、主机信任、密码存取往返、协议克隆和更新检查都有测试覆盖。

## 运行环境

- **Windows，64 位。** 这是一个 WPF 桌面程序，没有 macOS 或 Linux 版本。
- **Windows 10 2004（内部版本 19041）及以上**，或 Windows 11。这是项目所用 Windows SDK 的要求。
- 毛玻璃背景需要 **Windows 10 1803 及以上**。低于这个版本程序照常运行，只是界面不透明。
- 两个下载包中体积较小的那个需要 **.NET 9 桌面运行时（x64）**；自包含（self-contained）的那个什么都不用装。

## 下载与安装

没有安装程序。两个下载包都是解压即用的 zip。

1. 打开 [Releases](https://github.com/chaogei666661/1Remote-plus/releases) 挑最新的一版。
   侧边栏**不是**按日期排序的（原因见[更新检查](#更新检查)），要看版本号，别看它排在第几个。
2. 下载其中一个文件：

   | 文件 | 体积 | 前提 |
   | --- | --- | --- |
   | `1Remote-<版本号>-net9-x64.zip` | 较小 | 需已安装 .NET 9 桌面运行时（x64） |
   | `1Remote-<版本号>-net9-x64-self-contained.zip` | 较大 | 无，运行时已打包在内 |

   拿不准就选自包含的那个。

3. 解压到一个**你有写权限**的目录，例如 `D:\Apps\1Remote` 或者 U 盘。不要直接在压缩包里运行；除非你打算以
   管理员身份运行，否则也别放进 `C:\Program Files`。
4. 运行 `1Remote.exe`。

升级时关掉程序，把新 zip 解压覆盖到原目录再启动即可。配置、数据库和图标是独立文件，不会被覆盖。卸载就是删掉
这个目录。

## 首次运行

首次启动时程序会问你数据存在哪里，两个选项在同一个界面上：

- **便携模式**——所有数据都放在 `1Remote.exe` 旁边。放 U 盘、或者希望整套安装就是一个可以整体拷走的目录时选它。
- **为当前 Windows 用户配置**——所有数据都放在 Windows 的 `AppData` 目录里。程序目录只读时选它。

这个选择会以标记文件的形式记录在可执行文件旁边：`FORCE_INTO_PORTABLE_MODE` 或 `FORCE_INTO_APPDATA_MODE`。
**把其中一个改名成另一个**，下次启动就会切换模式；数据文件需要你自己搬。

服务器保存在本地 **SQLite** 数据库 `1Remote.db` 里，程序会自动创建，无需配置。注意数据库设置页上的那句提醒：
本地数据库**未加密**，请像对待任何存有密码的文件一样保护它。如果你更希望把列表放在服务器上，
`设置 → 数据库` 里可以添加 **MySQL** 或 **PostgreSQL** 数据源，与本地数据源并存。

## 添加第一个连接

1. 点击服务器列表上方的 **+** 按钮，选 **添加**。（导入的入口也在这个菜单里。）
2. 选一个协议——RDP、SSH、VNC、Telnet、SFTP、FTP、RemoteApp、串口，或者外部程序。
3. 填 **地址** 和 **端口**。端口会按协议预填默认值。
4. 填 **用户名** 和 **密码**，或者：
   - 留空密码，每次连接时再询问；
   - 从**凭据库**里选一条已保存的凭据；
   - 填 `cmd://<命令>`，连接时从密码管理器现取（见[凭据与密码](#凭据与密码)）。
5. **常规**分组里的可选项：
   - **标签**——输入名字后回车。列表的分组和筛选都靠标签。
   - **图标**和**备注**——点图标可以换成自己的图片。
6. 其他分组里的可选项，随协议不同：
   - **连接**——备用地址与备用账号，主地址不通时按顺序尝试；用于网络唤醒的 MAC 地址；这台服务器走哪个代理。
   - **显示**（RDP）——窗口 / 单显示器全屏 / 多显示器全屏，分辨率与缩放，性能档位。
   - **高级**（RDP）——剪贴板、驱动器、打印机、智能卡、声音、组合键、RD 网关。
   - **高级**（SSH）——私钥、启动命令、端口转发规则、代理转发（Pageant）、X11。
   - **连接前执行脚本 / 断开后执行脚本**——会话前后运行的命令行或 `.bat`。
7. **保存**，然后双击新条目即可连接。

第一次连到某台主机时，它的身份还未被认可，程序会显示指纹并询问是否记住。认可过的指纹写进
`.locality/known_hosts.json`；之后如果指纹变了会明确警告你，因为那要么意味着服务器被重装了，要么意味着连接
正在被劫持。确实改不了的机器——比如实验环境里用自签名证书的那台——可以在编辑页勾上**不验证该主机的身份**。

## 主窗口

**视图。** 主菜单的**视图**子菜单在**列表**、**卡片**、**树形**之间切换。树形按标签目录分组；列表和卡片是平铺
的，可以按固定在标题栏上的标签分组。

**搜索。** 按 **Ctrl + F** 跳到筛选框后直接输入。它会匹配名称、地址、用户名和备注，并支持标签语法：

| 输入 | 含义 |
| --- | --- |
| `web` | 匹配「web」的所有条目 |
| `#prod` | 只看带 `prod` 标签的服务器 |
| `#prod db` | 带 `prod` 标签**并且**匹配「db」 |
| `-#prod` | **排除**带 `prod` 标签的服务器 |

拼音、首字母之类的额外匹配方式可以在 `设置 → 启动器 → 关键词匹配器` 里开启，对这个筛选框和启动器都生效。

**标签。** 右键点标签可以**固定**到标题栏、**重命名**、**连接**该标签下的全部机器，或者**删除**。在列表行上的
标签块上：单击设为筛选条件，**Ctrl + 单击**加入包含列表，**Alt + 单击**加入排除列表。

**排序。** 主菜单的**排序**子菜单可以按 Id（也就是你自己拖出来的顺序）、协议、名称、地址，或者**最近连接过的
排前面**。协议、名称、地址三项再点一次会在升序和降序之间切换。

**可达性与连接质量。** 打开 `设置 → 常规 → 显示每台服务器是否可达` 后，程序会按固定间隔（默认 60 秒）向列表
中每台可见服务器所用的端口发起一次连接。它会走该服务器配置的代理；经由 SSH 跳板机的服务器不做探测。默认关闭，
因为这是对所有已配置主机的定时流量。

圆点不是只有绿红两种。每次探测的往返时延会保留最近十次，颜色由这十次的平均值、抖动（相邻两次之间的平均变化量）
以及无响应的次数共同决定：

| 圆点 | 含义 |
| --- | --- |
| 绿色 | 平均低于 60 毫秒，稳定，没有丢失 |
| 黄绿 | 低于 150 毫秒，或抖动不超过 50 毫秒 |
| 琥珀 | 低于 300 毫秒、抖动不超过 100 毫秒，或 5%–19% 无响应 |
| 橙色 | 300 毫秒及以上、抖动 100 毫秒及以上，或 20% 及以上无响应 |
| 红色 | 最近一次探测完全没有响应 |

把鼠标停在圆点上可以看到颜色背后的具体数字。这一切不会额外产生任何网络流量：分级是从本来就在跑的那轮探测里
算出来的，而不是靠一串突发探测包。

**托盘。** 默认情况下关闭窗口是最小化到托盘（`设置 → 常规 → 关闭按钮行为`）。托盘菜单可以列出最近用过的会话、
重置主窗口位置、打开问题反馈、显示关于，以及退出。

## 启动器

启动器才是让这个程序常驻后台的理由。在 Windows 的任何地方按下热键，搜索框就会浮在你当前正在做的事情之上。

- **Alt + M**——呼出。热键可以在 `设置 → 启动器` 里改，也可以在那里整个关掉。
- 输入即筛选，和主窗口一样支持 `#标签` 语法。
- **↑ / ↓**——上下移动选中项；**PageUp / PageDown** 一次移动五项。
- **Enter**——连接选中的服务器。
- **→**——展开该服务器的操作列表（新窗口打开、用备用凭据连接、指定启动器、复制密码、网络唤醒等等）。
  **←** 返回。
- **Tab**——在服务器列表和**快速连接**之间切换。
- **Esc** 或点击别处——隐藏启动器。

**快速连接**是启动器的第二种模式：直接输入 `192.168.0.100:3389` 这样的临时目标，不用先建条目就能连。之前用过
的快速连接会列在下面，用 **↑ / ↓** 选取。勾上**记住上述信息**就会把它存成正式的服务器条目；这个开关也可以
在 `设置 → 启动器` 里整个禁用。

`设置 → 启动器` 还能控制结果里是否显示备注和凭据，以及启用哪些**关键词匹配器**。想让热键随时可用，把
`设置 → 常规 → 开机自启动(最小化)` 打开。

## 会话、标签页与窗口

默认情况下每个会话都是同一个会话窗口里的一个标签页；把标签页拖出来可以撕成独立窗口，再拖回另一个窗口的标签栏
就会合并回去。`设置 → 常规 → 总在新窗口打开` 可以改变默认行为；任何条目也都能通过操作菜单里的
**连接 (新窗口)** 单次以新窗口打开。

会话窗口里：

- **Ctrl + 1 … Ctrl + 9**——切换到对应标签页。
- **F11**，或右键点最大化按钮——让**窗口**全屏。旁边工具栏上的全屏按钮是另一回事：它把当前**会话**移进一个
  专门的全屏窗口，多显示器 RDP 用的就是这个模式。
- **中键点标签页**——关闭它。标签页上还可以显示图标、重连、关闭三个按钮（`设置 → 常规`）。
- **发送命令**——工具栏上的按钮会打开一个对话框，把同一条命令输入到你勾选的每一个终端会话里。适用于 SSH、
  Telnet 和串口会话；RDP 和 VNC 无法用这种方式输入。常用的命令可以命名保存。
- RDP 会话掉线后会显示「重连中…」计数并自动重试；其他协议可以在标签页上显示**重连**按钮。
- SFTP 和 FTP 会话是一个文件浏览器：**F5** 刷新、**F2** 重命名、**Del** 删除、**Ctrl + S** 下载、
  **Ctrl + V** 从剪贴板上传。
- **会话录制**——`设置 → 常规 → 把终端会话输出录制到文件` 会把 SSH、Telnet、串口会话打印的一切写进
  `.sessionlogs/`（或你指定的目录）。默认关闭：会话日志里是屏幕上出现过的所有内容，经常包含本来不该留下的东西。
  录像会在每次启动时按目录旁边的两个上限清理——保留天数（默认 30）和总大小 MB（默认 1024）。任一项填 0 即关闭该
  限制；先删最旧的，且只动目录顶层的 `*.log`。
- **连接失败会被分类。** SSH、SFTP、FTP、VNC 和代理中继过去直接把底层库的原始报错打在错误面板上。现在会说明属于
  十五类中的哪一类——域名解析不出来、端口上没有服务在监听、凭据被拒绝、主机身份变了——原始报错保留在下面，并且只有
  重试确实可能成功的类别才提供重试。

## 连接审计日志

`设置 → 常规 → 连接审计` 在本机记录：什么时候、用哪个账号、经由哪个代理、连了哪台服务器、怎么结束的。这回答的是
事故之后一定会被问、而「最后连接时间」答不了的问题：谁连过那台主机、从哪台机器连的、成功了没有。

- 写到 `.locality/audit/connections-YYYY-MM-DD.jsonl`，一行一个 JSON 对象，按 UTC 日期一天一个文件。
- 每次连接有四个事件——发起、建立、失败、关闭——用连接 ID 串起来，关闭时带会话时长。
- **不含任何密钥。** 记录里只有服务器、地址、端口、远端账号、数据源、代理和结果，不会有密码、私钥或 `cmd://` 命令。
- 放在 `.locality` 下，所以不会跟着同步或共享的数据源跑到别处：它记的是**这台机器**上发生的事。
- 默认开启，保留 90 天。两者都可改；保留天数填 0 表示一直留着。
- 可**导出为 CSV** 供复盘或工单使用。以 `=`、`+`、`-`、`@` 开头的字段会加一个单引号前缀，这样别人填的服务器名在
  Excel 里打开时不会被当成公式执行。

## 诊断包

`设置 → 常规 → 诊断 → 生成诊断包` 会写出一个 zip，方便附在问题报告里：程序日志、运行环境报告（版本、操作系统、
运行时、区域设置）、你的设置和协议启动器定义。

里面每个文本文件在写入前都会脱敏。字段名里含 `password`、`passphrase`、`secret`、`token`、`privatekey`、
`credential` 等的值会被替换成 `[redacted]:<长度>`，PEM 私钥块、`cmd://` 外部取密命令、`-pw` / `--password`
参数同样处理。服务器数据库、凭据库、主机信任、命令批准、会话录像和审计日志根本不会被打进去，运行环境报告里也不含
你的账号名和机器名。

发出去之前请自己先看一遍。脱敏是对自由文本做的过滤，不是证明——填在一个名字不像密码的字段里的密码，仍然会留在里面。

了却连不上。

## 凭据与密码

**凭据库**（`设置 → 凭据库`）保存一组具名的「用户名 / 密码 / 私钥」条目。服务器条目可以按名字引用它，而不是各存
一份，于是换一次密码只需要改一处，不用改二十处。每台服务器还可以额外挂**备用**凭据，从操作菜单里选用。

**每次都问。** 密码留空，连接时就会弹窗询问。

**从密码管理器取。** 在密码框里填 `cmd://<命令>`，连接时就会执行这条命令，它在标准输出上打印的内容会被当作密码
使用。任何命令行工具都可以：

```
cmd://bw get password my-server
cmd://keepassxc-cli show -a Password ~/vault.kdbx my-server
cmd://pass show servers/my-server
cmd://op read op://Private/my-server/password
```

命令通过 `cmd.exe` 执行，所以管道和引号的行为与在命令行里一致。结尾的换行会被去掉；取到的值在本次运行期间会被
缓存（这样需要指纹或主密码的密码库只会问你一次）；超时时间为 20 秒。密码框旁边有**测试**按钮，它会跳过缓存执行
一次并告诉你返回了多少个字符。

**查看已保存的密码**——无论是在凭据库里还是通过「复制密码」——在 `设置 → 常规 → 安全设置` 打开该选项时需要通过
Windows 凭据验证。

**一句提醒。** 本地数据库和配置文件都未加密，备份包同样未加密，请照此保管。下面一节讲清楚这具体意味着什么。

## 安全须知

把某个构建指向你真正在意的密码库之前，请先读完这一节。

**没有加密盐的构建。** 保存密码所用的加密算法，其密钥是一个编译期常量，由 CI 从仓库 Secret 中替换进去。分支仓库
拿不到原始 Secret，因此在没有配置它的情况下构建出来的程序，用的仍是本仓库里公开的占位常量——一把谁都能读到的
钥匙。这样的构建会在启动时和「关于」页面里明确提示。**绝不要用它去打开官方发行版创建的密码库**：那会把真实密码
用一把已知的钥匙重新加密一遍。如果保存的密码需要真正受到保护，请自己带上自己的盐从源码构建。

**`1Remote.db` 能挡住什么。** 只能挡住随手翻看，仅此而已。干这件事的类叫 `UnSafeStringEncipher` 不是没有原因的：
它是用编译进二进制里的密钥做的混淆，不是按用户派生的加密。任何人只要同时拿到数据库文件和一份程序，就能还原出里面
所有的密码。请把这个数据库当作密码本身来保管。

**Windows Hello 管的是什么。** 二次验证保护的是程序运行期间的操作，例如查看或编辑某条已保存的凭据。它不是密钥：
无论是否启用 Hello，数据库的加密方式都完全一样，开启 Hello 不会让被拷走的数据库更难读。

**`cmd://` 外部密码本质上是执行命令。** 密码字段里可以填 `cmd://<命令行>`，连接时它会通过 `cmd.exe` 执行，输出
被当作密码使用。这意味着任何可写的数据源——共享的 SQLite 文件、被入侵的 MySQL/PostgreSQL 数据源、还原回来的备份、
导入的 mRemoteNG 文件——都可能变成一条代码执行路径。因此每一条不同的命令在本机首次运行前都必须先经过一次批准，
批准记录保存在本地的 `.locality/known_commands.json` 中，永远不会跟着数据库一起走。连接前/后脚本属于同一类功能，
同样适用这条提醒。

**WebDAV 备份要求 HTTPS。** 备份包里是整份配置，包含凭据数据库，而客户端会抢先发送 Basic 认证。除非在备份设置里
显式打开开关，否则明文 `http://` 会被拒绝——只有回环地址或实验环境才谈得上合理。

**SFTP 与 FTPS 会校验主机身份**：首次连接时记住指纹，之后如果指纹被悄悄换掉就拒绝连接；已接受的指纹保存在
`.locality/known_hosts.json`。

**SSH 跳板机现在也校验了。** 跳板机是本程序唯一自己发起的 SSH 连接，却恰恰是它没有校验：底层库在调用方不
拒绝的情况下会接受任何主机密钥，而此前没有任何地方拒绝过。于是跳板机的密码——或者用口令解开的私钥——会被
交给那个地址上应答的任何一方；又因为所有走代理的会话和所有常驻端口转发都跑在这一条通道里面，劫持一次握手
就等于拿到全部。现在跳板机和其他连接一样，首次使用时询问并记入同一个 `known_hosts.json`，与同一台机器作为
SFTP 服务器时的记录分开保存。升级后每台跳板机会提示一次；开机自启的端口转发会在启动时问。

**下载不会跑出你选的文件夹。** 递归下载时，每一个本地路径都是用服务器给出的名字拼出来的，而这两个协议都
不阻止服务器在目录列表里返回 `..\..\Startup\x.exe` 或者 `C:\Windows\System32\evil.dll`。现在这类名字会被
重新挂到目标文件夹下面；实在无法安放的，会直接拒绝——消息里带上那个名字，并在写入任何内容之前中止整个传输。
双击预览走的是同一套检查：预览会先把文件下载到临时目录再用关联程序打开，现在只有传输真正完成才会打开。

**远程文件名按真实内容显示。** 文件名可以被做成显示出来和实际内容不一样：一个真实名称为
`invoice<U+202E>gnp.exe` 的条目，在任何符合规范的文本渲染里都会画成 `invoiceexe.png`，在文件浏览器里双击
它就会启动一个程序。现在文件浏览器不再听从这些不可见的格式字符（双向文本覆盖、零宽连接符、控制字符），
而是把它们的码位直接写出来；预览这类文件时还会先询问，并给出真实名称和真正决定运行什么的扩展名。普通文件名
（包括带重音符号的和中日韩文字）显示方式不变。

**上传遇到文件夹链接会停下。** 上传文件夹过去会走进文件系统列出的每一个子目录，联接（junction）和符号链接
也不例外。链接指回上级目录时，扫描会不断以更长的路径重新进入同一棵树，直到系统先撑不住为止，然后这次上传就
悄无声息地什么也没做；链接指向别处时——`AppData`、映射的网络驱动器、整个 `C:\`——链接后面的内容会连同你真正
选中的文件夹一起被送到远端服务器。现在链接目录会在远端建成空文件夹、不再往里递归，传输面板会列出前几个停下
的链接，其余的只报个数——状态栏只有一行高，而一份普通的 Windows 用户配置里就有十几个兼容性联接，把完整列表
塞进去只会用你早就猜得到的内容把这一行填满。链接**文件**照常上传：顺着它读取本来就是「复制这个文件」的含义。
上传整个磁盘也能用了，会落到以盘符命名的文件夹里；以前它是静默失败的。

**读不了的文件夹不再让整次上传作废。** 每台 Windows 上都有属主自己也打不开的目录——`C:\System Volume
Information`、`$Recycle.Bin`、`C:\Users` 下别人的账户目录——你选中的文件夹下面只要有一个这样的目录，扫描
就会抛出异常并终止，而这个异常只写进日志：传输显示成功，实际一个字节都没发出去。上传盘符根目录必然踩到。
现在扫描会跳过列不出来的那个文件夹，照常上传其余内容，在服务器上把它建成空文件夹，并在传输面板里点名。

**临时文件。** 生成的 `.rdp` 文件和私钥副本放在每个会话专属的目录里，会话结束即删除，而不是丢在公共临时目录中。

**SSH 传输算法。** SFTP 会话、SSH 跳板机和常驻端口转发都通过内置的 SSH.NET 库协商。它提供 AES-GCM 和
ChaCha20-Poly1305、encrypt-then-MAC 完整性算法——后者正是 OpenSSH strict key exchange 生效的前提，也就是
Terrapin 攻击（CVE-2023-48795）的缓解措施——以及 `mlkem768x25519` / `sntrup761x25519` 后量子密钥交换。
OpenSSH 多年前就关掉的算法这里根本不会提供：arcfour、blowfish、CAST、Twofish、MD5 与 RIPEMD-160 系列 MAC、
截断的 `-96` 系列 MAC，以及 `ssh-dss` 主机密钥。老到只认这些算法的设备会协商失败；这种设备请改用 PuTTY，
本程序可以把它作为外部 SSH 运行器启动。

## 代理、跳板机与端口转发

在 `设置 → 代理` 里一次性定义好代理，然后在服务器编辑页为每台服务器选择。所有流量都经过本地中转，因此
**所有协议都覆盖，包括 RDP 和 VNC**，而不只是本身支持代理的那几个。

| 类型 | 说明 |
| --- | --- |
| SOCKS5 | 支持 IPv4、IPv6、远端域名解析，以及用户名/密码认证 |
| SOCKS4 | 域名在本地解析，代理只会看到一个 IPv4 地址 |
| SOCKS4a | 带远端域名解析扩展的 SOCKS4 |
| HTTP CONNECT | 可选的 Basic 代理认证 |
| SSH 跳板机 | 会话走在这台 SSH 服务器为你开到目标的通道里，等同于 OpenSSH 的 `ProxyJump`。先试私钥，再试密码。 |

每个代理都有**测试**按钮：填一个 `主机:端口` 的目标，它会告诉你这个代理能否连通。**地址就是本机时直接连接**会让
本地地址跳过代理。如果某台服务器指定的代理已被删除或信息不全，连接时会询问是否改为直连，而不是悄悄失败。

**端口转发**（`设置 → 端口转发`）跑的是独立于会话的常驻 SSH 隧道。每条转发都指向「代理」页上的一条 **SSH 跳板机**
条目——堡垒机只配置一次，两处共用，也共用同一次登录。

| 方向 | 作用 |
| --- | --- |
| 本地 | 在本机监听，经 SSH 主机转发到 `目标:端口` |
| 远程 | 在 SSH 主机上监听，回传到本机能访问到的某个目标 |
| 动态 | 在本地端口上开一个 SOCKS 代理，没有固定目标 |

转发可以**随软件启动自动开启**。监听地址填 `0.0.0.0` 而不是 `127.0.0.1`，等于把隧道开放给整个网络，编辑器里
会明确提示这一点。

跟随会话的 SSH 转发也还在，在 SSH 条目的**高级**分组里：一行一条规则，写成 `L 8080 intranet:80` /
`R 9000 localhost:9000` / `D 1080`，或者 PuTTY 自己的 `L8080=intranet:80` 语法都行。

## 备份与还原

`设置 → 备份` 会把上表里的东西——服务器、凭据库、全部设置、标签、连接记录、自定义启动器、图标——打包成一个文件。

- **创建备份**：把备份包写到你指定的位置。
- **从备份还原**：用备份里的内容替换当前数据，然后关闭程序；重新启动才会用上还原后的数据。此操作**不可撤销**。
- **异地备份（WebDAV）**：把同一个备份包上传到 WebDAV 目录——Nextcloud、ownCloud、群晖以及多数 NAS 都支持。
  填一个形如 `https://cloud.example.com/remote.php/dav/files/me/1Remote/` 的目录地址加上用户名密码，然后使用
  **备份并上传**、**刷新列表**、**下载并恢复**。

存在远程 MySQL 或 PostgreSQL 数据源里的服务器留在那个数据库里，备份只记录连上它所需的信息。

备份包里的配置是**未加密**的。请使用 HTTPS 地址，并放在只有你能访问的目录里。

## 导入与导出

在服务器列表上方的 **+** 菜单里：

- **导入 json**——1Remote Plus 自己导出的列表，或上游 1Remote 导出的列表。
- **导入 mRemoteNG csv**——参见上游的
  [mRemoteNG 导入说明](https://1remote.github.io/usage/overview/#importing-from-mremoteng)。
- **从 `~/.ssh/config` 导入**——读取你的 OpenSSH 配置；其中的 `ProxyJump` 会自动在「代理」页上生成对应的
  SSH 跳板机条目。`Include` 会被跟进（支持通配符、`~`、以及相对 `~/.ssh` 的路径，最多 16 层），所以拆分在
  `~/.ssh/config.d/*` 里的配置也能整份导入。`Host *`、`Host *.internal` 这类模式块会按 ssh 的语义当作默认值
  应用，而不是直接丢掉，并遵循 ssh「整份文件里先出现的值胜出」的顺序；`Match` 段在条件是 `all`、`host`、
  `originalhost` 时会被读取，条件是导入对话框无法回答的那些（`exec`、`user`、`localnetwork`、`tagged` 等）
  时整段跳过。
- **导入 \*.rdp**——远程桌面文件。
- **导入 PRemoteM db**——本程序早期名字下的数据库。

**导出**会把当前选中的服务器写成 JSON。单个 RDP 条目还可以从它的操作菜单导出成 `.rdp`。

## 外观：主题、毛玻璃、语言

`设置 → 主题` 可以选配色、字体和字号（10–20）。

毛玻璃配色：**Dark**、Mica Slate、Nord Frost、Tokyo Night、Catppuccin Mocha、Emerald Glass、Cyber Neon、
Rose Pine、macOS Light Glass。
经典配色：Light、PRemoteM、SecretKey、Greystone、Asphalt、Wine、Forest、Soil 等。任何一套都可以逐色改。

**毛玻璃**有自己的开关——*面板背后模糊桌面（需 Windows 10 1803 及以上）*——以及一个**面板不透明度**滑块。低于
120 左右，文字在花哨的桌面背景上就开始看不清；高于 230 左右，模糊效果基本看不出来了。

关于毛玻璃有两点实话。一是它在**远程桌面会话中**和**高对比度模式下**会自动关闭，因为此时 DWM 采样的是远端的
帧缓冲而不是真实桌面，面板会糊成一片；程序会切回不透明表面，保证可读。二是**会话窗口、会话全屏窗口和崩溃报告
窗口按设计始终不透明**——前两者内嵌了远程桌面的 HWND，DWM 模糊会在上面糊出一层雾；后者外围画了一圈透明留白，
加上毛玻璃会变成一个方形光晕。

**语言。** `设置 → 常规 → 语言` 提供 English、简体中文、繁體中文、日本語、Deutsch、Français、Español (AR)、
Galego、Italiano、Polski、Português (BR/PT)、Русский、Čeština。

## 更新检查

程序每小时检查一次新版本，读的是**本分支**的 releases 页面
`https://github.com/chaogei666661/1Remote-plus/releases`，不会去看上游。可以在 `设置 → 常规 → 不检查新版本` 里关掉。
没有自动更新器，检查到新版本只是告诉你并给出链接。

**手动下载时值得知道的一个坑。** GitHub 的 releases 侧边栏是按标签名的**字符串**排序的，所以
`v1.3.0.12-beta` 会排在 `v1.3.0.1-beta` 和 `v1.3.0.2-beta` 之间，而不是最上面。**排在第一个的不一定是最新的。**
请按发布日期排序，或者直接看版本号取最大的那个。（程序内的检查是按数值比较的，不会被这个骗到；本页顶部的版本
徽章也是出于同样的原因加了 `sort=semver`。）

## 排查问题

**只有配了代理才连不上。** 打开 `设置 → 代理`，选中那条代理，在**测试目标**里填 `主机:端口` 然后点**测试**。
它会告诉你代理本身能否连通目标。

**每次连接都提示「未验证的主机」。** 指纹没被记住，通常是因为程序写不了 `.locality/known_hosts.json`。
检查一下数据目录是否可写。

**窗口没有毛玻璃效果。** 在远程桌面会话中、高对比度模式下、Windows 10 1803 之前的系统上，以及主题里毛玻璃
开关关着的时候，这都是预期行为。会话窗口本身按设计就是不透明的。

**启动时提示「我们没有 …… 目录的写入权限」。** 存放配置的目录是只读的。把程序挪到可写的位置，或者重启后选择
*为当前 Windows 用户配置*，把数据放进 `AppData`。

**想看更多细节。** 把 `设置 → 常规 → Log level` 调到更详细的档位，然后看 `.logs/1Remote.log.md`，
提 issue 时把相关片段贴上。

## 从源码构建

见 **[DEVELOP.md](DEVELOP.md)**（英文）。简单说：Windows 上用 Visual Studio 2022，还原 NuGet 包，编译
`1Remote.sln`。发布包由
[`.github/workflows/build-on-dev-push.yml`](.github/workflows/build-on-dev-push.yml) 产出，也就是上面那两个 zip。

注意：分支仓库不会继承上游仓库的构建密钥。缺了它们，遥测是空转的，字符串加密盐会回退到一个公开的常量——因此你
自己构建出来的版本**不要**去打开由官方发布版创建的密码存储。
