## Blocker: cloud subagent quota exhausted

The optional final step — booting a *separate* fresh agent from the build to re-verify — could not run:
launching any cloud subagent returns "You've used all included Cloud Agent usage. Enable on-demand usage".
This is an account-usage setting, not a repo problem. It also blocks the orchestrator's core requirement
of spawning `environment: cloud` subagents, so the multi-agent loop cannot fan out until on-demand cloud
usage is enabled. Environment validation itself is unaffected (covered by the local runs + the draft build).
